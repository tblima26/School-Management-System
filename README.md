Sistema de gestão escolar moderno, responsivo e pensado para organizar a rotina acadêmica de forma prática e eficiente. A aplicação centraliza o controle de alunos, professores, cursos, notas e configurações em uma única interface amigável.

## ✨ Visão geral

Este projeto foi desenvolvido para facilitar a administração escolar com uma interface intuitiva, buscas rápidas, organização visual dos dados e foco na experiência do usuário. É uma solução ideal para estudo, prototipagem e evolução de sistemas acadêmicos.

## 🚀 Funcionalidades

- 📊 Dashboard administrativo com visão geral da instituição
- 👨‍🎓 Gestão de alunos
- 👩‍🏫 Gestão de professores
- 📚 Cadastro e organização de cursos
- 📝 Controle de notas e avaliações
- ⚙️ Área de configurações do sistema
- 🎨 Interface moderna com componentes reutilizáveis
- 📱 Layout responsivo para desktop e dispositivos móveis

## 🛠️ Stack tecnológica

- Angular 22
- TypeScript
- Tailwind CSS
- Spartan UI
- Ng Icons
- RxJS
- Angular Router

## ✅ Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- Node.js 18+
- npm
- Git

## 📦 Instalação

```bash
git clone https://github.com/seu-usuario/School-Management-System.git
cd School-Management-System
npm install
```

## ▶️ Como executar

### Ambiente de desenvolvimento

```bash
npm start
```

A aplicação será iniciada em modo de desenvolvimento e normalmente estará disponível em:

```bash
http://localhost:5000
```

### Build de produção

```bash
npm run build
```

### Testes

```bash
npm test
```

## 🧩 Scripts disponíveis

